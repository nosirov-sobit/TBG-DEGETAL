Ma’lumotlar va zaxira

Bu sahifadagi ma’lumotlar faqat shu brauzerga tegishli. JSON faylni xodimlar bilan maxfiy kanalda baham ko‘ring; ommaviy GitHub’ga shaxsiy ma’lumotlar bazasini yuklamang.
Ma’lumotlar ushbu qurilmaning brauzer xotirasida saqlanadi. Jamoaviy server, akkaunt va markaziy baza hozircha yo‘q.

Eksport

JSON: obyektlar, fotosuratlar va monitoring tarixi. CSV: obyektlar reyestri; Excel dasturida ochiladi.

Import

Import qilishdan oldin zaxira nusxa oling. Importdagi ma’lumotlar mavjud obyektlar ro‘yxatini almashtiradi.

Ma’lumot xavfsizligi

Brauzer xotirasini tozalash yoki boshqa manzildan HTML ochish avvalgi yozuvlarni ko‘rsatmasligi mumkin. JSON eksport/importdan foydalaning. Bu sinov platformasi, rasmiy markazlashgan ma’lumotlar bazasi emas.
